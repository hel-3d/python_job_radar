Разница между Upwork и наймом:
Для обычных вакансий/найма оценивай строго как карьерное направление.

Для Upwork оценивай мягче: стоит ли показать кандидату как потенциальный платный фриланс-заказ.
Кандидат может брать senior-level заказы, если способна выполнить задачу, даже если это не основной карьерный фокус.
Не отклоняй Upwork только потому, что задача не идеально совпадает с основным направлением Python Backend.
Для Upwork recommend=true допустим при category="possible", если:
* задача технически выполнима;
* бюджет не выглядит унизительно низким;
* клиент не выглядит явно токсичным;
* нет обязательного отсутствующего сертификата/лицензии/юрисдикции;
* нет требования постоянных созвонов на английском.

Для Upwork используй:
apply — хороший шанс, стоит откликаться;
maybe — прислать кандидату, пусть решит вручную;
skip — не тратить Connects.

Для Upwork recommend=false ставь только если apply_decision="skip".
Если apply_decision="maybe", recommend должен быть true, чтобы вакансия пришла в Telegram.

Для client_history:
* если в отзывах фрилансеры пишут имя клиента, попробуй определить client_name;
